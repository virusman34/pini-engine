# Pini Editor — PySide6 preview (Windows x64)

1. Extract the entire ZIP to a writable folder.
2. Keep `PiniEditor.exe` and `_internal` together, then run `PiniEditor.exe`.
3. Choose a workspace and use the `예제` tab to copy a sample project.

Python and Visual Studio are not required to run this ZIP. The editor's basic scene and asset workflows were tested on Windows 11 x64. Windows and Android game export are not yet validated.
